# Flexible 6–12 month career path using real projects

Every stage should contain a real bounded shipping objective, an unaided coding lab, benchmark evidence and a verbal defense. Time allocations are suggestions, not promises.

**Weeks 1–4:** Brownfield audit, write tests, Python types/data structures, SQL joins and indexing, identify one actual workflow baseline. Independently implement state machine and safe retrieval lookup.

**Months 2–3:** Versioned ingestion, ACL enforcement, retrieval metrics, API contract testing; independently create evaluator and ingestion tombstone reconciler.

**Months 3–4:** Durable jobs, concurrency/transaction tests, tracing; independently build idempotency service with fault-injection simulation.

**Months 4–6:** Agent orchestration, bounded tools, authorization, failure recovery, comparative evaluation against deterministic baseline; independently code coordinator core.

**Months 6–8:** Manufacturing system intelligence and operational-file validation with source provenance/versions; independently build dependency graph analyzer and validator adapter.

**Months 8–10:** Production operations, SLOs, runbooks, regression gates, synthetic load tests, security audit; independently diagnose an introduced race/failure.

**Months 10–12:** Multi-team reusable platform integration (if approved), controlled business impact study, Staff-level architecture review, 4–6 sanitized case studies and mock interviews.

Do not force features to satisfy coursework. Prioritize real organization needs, then use them to select the correct technical study.
