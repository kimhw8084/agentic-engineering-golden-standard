# Security policy
This public-safe starter uses entirely synthetic fixtures; **it is not certified or authorized for production**.
Do not open issues or discussions containing restricted company information, credentials, proprietary production recipes, employee communications, customer information or internal hostnames.

For any production deployment, require company authentication, per-source authorization, secure secrets storage, network controls, retention and deletion policies, audit evidence, human review, domain validators and a separate approved action executor. The demo's caller-supplied roles and reviewer flags are NOT real authentication/approval systems.

Never permit this template's demo utilities to issue MES, SECS/GEM, equipment, recipe, production database or deployment writes. Adapt only after independent information-security and operational approvals.

Report vulnerabilities privately to the eventual repository owner under organization policy; do not disclose secrets in public issues.
